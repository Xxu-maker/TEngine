# 3-6. 配置表模块（CSV 直读）

> 本章已随工程改造重写：**配置表不再使用 Luban**，改为 CSV 直接作为数据源。

## 📊 模块概述

原方案的链路是：策划改 Excel → 跑 Luban 工具（需 .NET SDK + 克隆 luban 仓库 + 生成 bytes）→ 生成 C# 代码与二进制 → 打包进 AB → 运行时反序列化。

问题在于**链路长、依赖重、中间产物多**：换台机器要先 `build-luban`，改一个数字要走一遍生成脚本，生成代码和 Excel 模板对不齐就容易出错。

现方案：**策划直接维护 CSV，运行时直接解析**。没有导表步骤、没有生成代码、没有中间产物。CSV 依然是 YooAsset 的普通资源，热更能力不受影响。

---

## 📁 数据放在哪

```
Assets/AssetRaw/Configs/*.csv
```

该目录已在 YooAsset 的 `Configs` 收集组内（`AddressByFileName` + `CollectAll`），所以：

- CSV 放进即被收集，**无需任何额外配置**；
- 资源地址 = 文件名（不含扩展名），`item.csv` → `"item"`；
- 随 AssetBundle 走，**天然参与热更**。

---

## ✍️ CSV 怎么写

### 推荐格式（Excel 直接导出即可）

```csv
id,name,hp,isBoss,spawnPos,dropList
int,string,int,bool,vector3,string
1001,小怪,100,false,"1,2,3","1001,2;1002,3"
1002,Boss,5000,true,"10,0,5",""
```

- 第 1 行：字段名
- 第 2 行：类型（可整行省略，省略时全部按 string 处理）
- 第 3 行起：数据；以 `#` 开头的行是注释

### 兼容 Luban 表头

旧 xlsx 导出成 CSV 后基本可以直接用：

```csv
##var,id,name,hp,isBoss
##type,int,string,int,bool
##group,c,s,c,c
1001,小怪,100,false
```

`##var` 行是字段名，`##type` 行是类型，`##group` / `##` 等其它指令行自动忽略。

### 类型与写法

| 类型 | 写法 | 备注 |
|------|------|------|
| `int` / `long` / `float` / `double` | `100`、`1.5` | 与系统语言无关（InvariantCulture） |
| `bool` | `true` / `1` / `yes` / `是` | 其余为假 |
| `string` | 任意文本 | 含逗号或换行要用双引号包裹 |
| `vector2` / `vector3` | `"1,2,3"` 或 `1;2;3` | **含逗号必须加引号** |
| 列表 | `"1001,2;1002,3"` | 默认按 `;` 拆分 |
| 枚举等其它 | `WHITE` | 按 string 处理，代码里自行映射 |

**主键**：名为 `id` 的列；没有 `id` 列时取第 1 列。

**编码**：务必存成 UTF-8（Excel 里选「CSV UTF-8」），否则中文会乱码。

## 💻 代码里怎么读

```csharp
using GameLogic;

// 加载（首次加载后缓存，同一张表并发加载会合并为一次）
CsvTable item = await GameModule.Csv.LoadTableAsync("item");

// 按主键取行
CsvRow row = item.Get(10002);
if (item.TryGet(99999, out CsvRow maybe)) { /* 存在才用 */ }

// 取值
string name = row.GetString("name");
int    hp   = row.GetInt("hp", 0);
bool   boss = row.GetBool("isBoss");
Vector3 pos = row.GetVector3("spawnPos");
string[] drops = row.GetArray("dropList");

// 遍历
foreach (CsvRow r in item.Rows) { /* ... */ }

// 释放（归还 TextAsset）
GameModule.Csv.ReleaseTable("item");
```

模块实现位于 `Assets/GameScripts/HotFix/GameLogic/Config/`，属于**热更程序集**，改解析逻辑不需要重新出包。

## 🧯 常见问题

| 现象 | 原因 | 解决 |
|------|------|------|
| 抛"资源不存在" | 文件名与表名不一致，或没刷新 | 确认文件在 `Assets/AssetRaw/Configs/`，执行一次刷新 |
| 整表都读成字符串 | 第 2 行有格子不是合法类型名，整行被当成数据 | 检查类型行 |
| `GetVector3` 取不到 | 单元格没加双引号，逗号被当作列分隔 | 写成 `"1,2,3"` |
| 中文乱码 | 不是 UTF-8 | 导出时选「CSV UTF-8」 |
| 热更后表没变 | 资源没重新打包 | 走 YooAsset 打包流程 |
